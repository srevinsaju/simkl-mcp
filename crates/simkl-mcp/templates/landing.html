Run your own

Register a Simkl app with the redirect URI https://<your-host>/auth/simkl/callback, then build and run the image. Self-hosting has the details.

docker build -t simkl-mcp https://github.com/srevinsaju/simkl-mcp.git
docker run -p 8080:8080 -v simkl-mcp:/data \
  -e SIMKL_MCP_PUBLIC_URL=https://<your-host> \
  -e SIMKL_MCP_CLIENT__CLIENT_ID=YOUR_CLIENT_ID \
  -e SIMKL_MCP_CLIENT_SECRET=YOUR_CLIENT_SECRET \
  -e SIMKL_MCP_VAULT_KEY=YOUR_VAULT_KEY \
  simkl-mcp

Make YOUR_VAULT_KEY once with openssl rand -base64 32: a new key signs everyone out.
